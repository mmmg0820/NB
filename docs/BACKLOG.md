# 통합 후속 작업

기준 앱: R2 `b4ffe8718bf01b02930468451baa4ecab45f1db3`. 아래 코드는 이번 문서/포인터 수정에 포함하지 않았다.

| ID | 상태 | 담당/범위 | 완료 조건 |
| --- | --- | --- | --- |
| O-01 | 구현·검사 완료, 게시 커밋으로 추적 | 운영: 기본 evidence를 R2로 연결, R1 원문 보존 | 포인터와 APK/소스 SHA 일치, R1 원문 바이트 일치, 새 커밋 게시 |
| A-01 | PENDING_ANDROID_QA | Android 통합; 상세 구현 범위는 원본 할당과 제출 근거로 확정 | Android 빌드·테스트 및 정확한 후보 SHA의 QA 승인 후 별도 successor 커밋 |
| T-05 | PENDING | 타로 담당/추적성; 원본 할당 기준 후속 작업 | 코드·문서 일치 및 관련 회귀 승인 |
| R-01 | PENDING | 기록 담당/Android 통합; 원본 할당 기준 후속 작업 | 기존 기록·저장 포맷 호환성을 명시하고 Android/QA 승인 |

ID만으로 상세 구현을 추측하지 않는다. 타로 공통 요약 등 최신 요구는 [Android 플랫폼](android-platform/README.md)과 [디자인 시스템](design-system/README.md)의 후속 계약을 읽고 조정 담당 할당과 대조한다.

통합 중 확인한 별도 정정 과제: [타로 스프레드](tarot-spreads/README.md) 제출 원문의 78장 적응형·5열 모드 설명은 b4ffe871 코드와 다르다. 현재 78장 그리드는 8열×10행이며 `TarotSelectionLayoutMode`는 기준 코드에 없다. 원문은 정정 주석과 함께 보존했고 상세 정정은 타로 담당에게 인계한다.

A-01/T-05/R-01 완료 선언은 하지 않았다. 이번 문서 커밋으로 APK나 기존 앱 태그를 바꾸지 않는다.
